# Portfolio Overview

This directory contains my software development portfolio, organized by different technology and focus areas.

Each subfolder represents a specific domain of development and contains projects, experiments, and learning exercises related to that area.  
The purpose of this structure is to keep the portfolio clear, scalable, and easy to navigate for both learning and presentation purposes.

Each portfolio section includes its own README file with more detailed descriptions of the projects, technologies used, and learning goals.

---

## Quick Start (EN)

- Open the repository root `index.html` to view the main portfolio hub (recommended).
- Alternatively, open `portfolio/portfolio_web/index.html` to browse only the web demo projects.
- Recommended setup: **VS Code + Live Server extension** for best local experience.

---

## Portfolio Sections

- **portfolio_web**  
  Web development demo projects focusing on HTML, CSS, JavaScript, and frontend fundamentals.  
  This section contains multiple small demo sites, each in its own folder, as well as a hub page for browsing the demos locally and later via GitHub Pages.

- **portfolio_frontend**  
  Frontend-focused projects, including modern UI practices and framework-based development.

- **portfolio_backend**  
  Backend-related projects and experiments (planned and upcoming as studies progress).

- **portfolio_fullstack**  
  Projects combining frontend and backend development.

- **portfolio_mobile**  
  Mobile application development projects and prototypes.

- **portfolio_desktop**  
  Desktop application projects and experiments.

- **portfolio_games**  
  Game development projects and interactive applications.

- **portfolio_3d**  
  3D-related projects, including modeling, visualization, and interactive environments.

- **portfolio_trading**  
  Trading-related projects such as indicators, data analysis tools, and algorithmic experiments.

---

## Structure Philosophy

This portfolio is designed to evolve over time.  
New projects and technologies will be added gradually as my skills and studies progress.

Demo projects (especially in `portfolio_web`) focus on practicing UI design, layout, HTML, CSS, and JavaScript fundamentals.  
Other sections will increasingly focus on more complete, real-world applications and larger technical systems.

The focus is on:
- Clear structure  
- Real projects instead of isolated experiments  
- Continuous learning and improvement

# Portfolion yleiskuvaus

Tämä kansio sisältää ohjelmistokehitysportfolioni, joka on jaettu eri teknologia- ja osa-alueisiin.

Jokainen alikansio edustaa tiettyä kehityksen osa-aluetta ja sisältää siihen liittyviä projekteja, kokeiluja ja oppimistehtäviä.  
Rakenteen tarkoituksena on pitää portfolio selkeänä, laajennettavana ja helposti hahmotettavana sekä oppimisen että esittelyn näkökulmasta.

Jokaisella portfolio-osiolla on oma README-tiedosto, josta löytyvät tarkemmat kuvaukset projekteista, käytetyistä teknologioista ja oppimistavoitteista.

## Rakenteen periaate

Tämä portfolio on suunniteltu kehittymään ajan myötä.  
Uusia projekteja ja teknologioita lisätään sitä mukaa, kun osaamiseni ja opintoni etenevät.

Web-demot (erityisesti `portfolio_web`-osiossa) keskittyvät käyttöliittymiin, rakenteisiin ja frontend-tekniikoiden harjoitteluun.  
Muut osiot painottuvat yhä enemmän kokonaisvaltaisiin sovelluksiin ja oikean maailman projekteihin.

Painopiste on:
- Selkeä rakenne  
- Oikeat projektit irrallisten kokeilujen sijaan  
- Jatkuva oppiminen ja kehittyminen
