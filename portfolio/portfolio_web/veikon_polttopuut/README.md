# Veikon Polttopuut (portfolio demo)

A rustic, light-themed firewood business landing page.
Built to feel different from the dark/tech demos: warm “wood & ember” accents, delivery ZIP check, and a quote calculator.

## Sticky header / anchor fix
This demo includes an anchor offset fix so headings aren’t hidden under the sticky header:
- `html { scroll-padding-top: ... }`
- `section { scroll-margin-top: ... }`

## Features
- Light rustic UI (wood/ember accents)
- Responsive sticky navigation + mobile menu
- ZIP checker (demo delivery fee)
- Price estimate calculator (product + quantity + delivery)
- Contact form with lightweight validation (demo)

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser or use VS Code **Live Server**.
