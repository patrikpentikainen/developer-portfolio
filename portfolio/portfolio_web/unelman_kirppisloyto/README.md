# Unelman Kirppislöytö (portfolio demo)

A light, warm “paper style” second-hand / flea market demo page.
Built to look different from the dark-themed demos: red + yellow accents, playful cards, and a simple wishlist.

## Key improvements vs sticky header issue
This demo includes an anchor-offset fix so section headings are not hidden under the sticky header:
- `html { scroll-padding-top: ... }`
- `section { scroll-margin-top: ... }`

## Features
- Light theme (paper feel), red/yellow accents
- Category chips + search (Vanilla JS)
- Card layout with “price tag” look
- Wishlist using `localStorage` (add/remove/clear)
- Responsive navigation + mobile menu

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` or use VS Code **Live Server**.

# Unelman Kirppislöytö (portfolio-demo)

Vaalea ja lämmin “paperinen” kirppis/second-hand demo-sivu.
Tarkoituksella erilainen kuin tumma teema: punainen + keltainen aksentti, leikkisät kortit ja yksinkertainen muistilista.

## Tärkeä parannus sticky-header ongelmaan
Tässä demossa ankkurilinkit eivät peitä otsikkoa valikon alle:
- `html { scroll-padding-top: ... }`
- `section { scroll-margin-top: ... }`

## Ominaisuudet
- Vaalea teema, punainen/keltainen aksentti
- Kategoriat + haku (Vanilla JS)
- “Hintalappu” -fiilis korteissa
- Muistilista `localStorage`:lla (lisää/poista/tyhjennä)
- Responsiivinen navigaatio + mobiilivalikko

## Teknologiat
- HTML5
- CSS3
- Vanilla JavaScript

## Käyttö
Avaa `index.html` selaimessa tai käytä VS Coden **Live Server** -laajennusta.
