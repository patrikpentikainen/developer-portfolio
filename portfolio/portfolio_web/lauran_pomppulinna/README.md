# Lauran Pomppulinna (portfolio demo)

A high-energy “neon confetti” one-page website for a bounce house rental concept.  
Built with HTML/CSS/Vanilla JS to showcase variety in visual style and interactions across portfolio projects.

## What’s included
- Neon dark UI + energetic hero
- Package cards (Mini/Party/Mega)
- “Availability checker” (demo logic)
- FAQ accordion (Vanilla JS)
- Booking form with lightweight validation (demo)
- Package selection auto-fills the form (Vanilla JS)

## Tech stack
- HTML5
- CSS3 (responsive layout, neon gradients)
- Vanilla JavaScript (availability demo, accordion, validation)

## How to run
Open `index.html` in a browser or use **Live Server** in VS Code.

## Notes
This is a demo project. No real booking or messages are sent.
