# Konemiehen & Pojan Vaihtokone (portfolio demo)

A light-themed “retro industrial” one-page website built with HTML/CSS/JavaScript for portfolio purposes.  
This project intentionally uses a different structure and visual style than the other demo pages to avoid a repeated template look.

## What’s included
- Light “paper” UI with industrial accent colors
- Pricing section (3 plans)
- Comparison table (responsive container)
- Mini price estimator (JavaScript)
- Quote request modal with simple validation (demo)

## Tech stack
- HTML5
- CSS3 (responsive layout, table container, modal UI)
- Vanilla JavaScript (calculator, modal, validation)

## How to run
Open `index.html` in a browser or use **Live Server** in VS Code.

## Notes
This is a demo project. The quote form does not send real messages — it validates input and shows a success note.

# Konemiehen & Pojan Vaihtokone (portfolio-demo)

Vaalea “retro-industrial” yhden sivun sivusto (HTML/CSS/JS), tehty portfoliota varten.  
Tässä projektissa on tarkoituksella eri rakenne ja ulkoasu kuin muissa demo-sivuissa, jotta portfolio ei näytä samalta templatelta joka kerta.

## Mitä mukana
- Vaalea “paperimainen” UI + teolliset korostevärit
- Hinnasto (3 pakettia)
- Vertailutaulukko (responsiivinen container)
- Pieni hinta-arviolaskuri (JavaScript)
- Tarjouspyynnön modaali + kevyt validointi (demo)

## Teknologiat
- HTML5
- CSS3 (responsiivisuus, taulukko-container, modaali)
- Vanilla JavaScript (laskuri, modaali, validointi)

## Käyttö
Avaa `index.html` selaimessa tai käytä VS Coden **Live Server** -laajennusta.

## Huomio
Tämä on demo-projekti. Tarjouspyyntö ei lähetä oikeaa viestiä — se validoi kentät ja näyttää onnistumisviestin.
