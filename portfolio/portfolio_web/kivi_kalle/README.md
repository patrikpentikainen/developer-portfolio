# Kivi & Kalle (portfolio demo)

A modern one-page business website built with plain HTML/CSS/JavaScript for portfolio purposes.  
The goal of this project is to demonstrate a clean “company-style” layout and a few interactive UI features without any frameworks.

## What this demo includes
- Sticky navigation + mobile menu
- Scrollspy-style active navigation highlighting while scrolling
- Service and project cards (responsive grid)
- FAQ accordion (JavaScript)
- Contact form with simple validation (demo)

## Tech stack
- HTML5
- CSS3 (Grid/Flexbox, responsive layout)
- Vanilla JavaScript

## How to run
Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

## Notes
This is a demo project. The contact form does not send real emails — it only validates input and shows a success message.

# Kivi & Kalle (portfolio-demo)

Moderni yhden sivun yrityssivu (HTML/CSS/JS), tehty portfoliota varten.  
Tavoitteena on näyttää siisti yritys-tyylinen ulkoasu ja muutamia käyttöliittymäominaisuuksia ilman kirjastoja tai frameworkeja.

## Mitä tässä demonstroidaan?

- “Scrollspy”: aktiivinen linkki korostuu scrollatessa
- Palvelu- ja projektikortit (responsiivinen grid)
- FAQ-accordion (JavaScript)
- Yhteydenottolomake + yksinkertainen validointi (demo)

## Teknologiat
- HTML5
- CSS3 (Grid/Flexbox, responsiivisuus)
- Vanilla JavaScript

## Käyttö
Avaa `index.html` selaimessa tai käytä VS Coden **Live Server** -laajennusta.

Tämä on demo-projekti. Lomake ei lähetä oikeaa sähköpostia — se vain validoi kentät ja näyttää onnistumisviestin.
