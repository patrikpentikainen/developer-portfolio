# Kukallinen Leena (portfolio demo)

A boutique florist one-page website built with HTML/CSS/JavaScript for portfolio purposes.  
This page is intentionally styled with a soft pastel “boutique” look to stand out from the other demo sites in the portfolio.

## What’s included
- Pastel boutique UI (light theme)
- Seasonal bouquet list with category filtering (Vanilla JS)
- Gallery with a simple lightbox (Vanilla JS)
- Contact/order form with lightweight validation (demo)

## Tech stack
- HTML5
- CSS3 (responsive layout, cards, gradients)
- Vanilla JavaScript (filter, lightbox, form validation)

## How to run
Open `index.html` in a browser or use **Live Server** in VS Code.

## Notes
This is a demo project. The form does not send real messages.
