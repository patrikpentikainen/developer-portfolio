# Liisan Verkkokauppa (portfolio demo)

A micro e-commerce demo built with HTML/CSS/Vanilla JavaScript.
The goal is to showcase interactive UI patterns: product grid, cart drawer, quantity stepper, totals, and a coupon code.

## Features
- Product grid with category filters
- Search input (client-side)
- Cart drawer (open/close, ESC to close)
- Quantity controls (+/−), remove item, clear cart
- Order summary (subtotal, discount, shipping, total)
- Coupon demo: `LIISA10` (−10%)
- Shipping demo: 4.90€ or free over 60€

## Tech stack
- HTML5
- CSS3 (responsive layout)
- Vanilla JavaScript (state + rendering)

## Run locally
Open `index.html` in a browser or use **Live Server** in VS Code.

## Notes
This is a demo project. No real checkout or payments are performed.

# Liisan Verkkokauppa (portfolio-demo)

Micro-ecommerce demo HTML/CSS/Vanilla JavaScript -tekniikoilla.
Tavoite on näyttää interaktiivisia UI-malleja: tuotegrid, ostoskori sivusta (drawer), määrän muutos, summat ja kuponki.

- Ostoskori drawer (auki/kiinni, ESC sulkee)
- Määränmuutos (+/−), poisto, korin tyhjennys
- Yhteenveto (välisummaa, alennus, toimitus, yhteensä)
- Kuponki-demo: `LIISA10` (−10%)
- Toimitus-demo: 4.90€ tai ilmainen yli 60€

## Teknologiat
- HTML5
- CSS3 (responsiivinen layout)
- Vanilla JavaScript (tila + renderöinti)

## Käyttö
Avaa `index.html` selaimessa tai käytä VS Coden **Live Server** -laajennusta.

Tämä on demo-projekti. Maksua ei suoriteta oikeasti.
