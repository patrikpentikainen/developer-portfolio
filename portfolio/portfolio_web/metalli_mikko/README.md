# Metalli Mikko (portfolio demo)

Industrial one-page website concept for a metal workshop / machine shop business.
Designed to look different from other portfolio pages: steel/dark theme, orange accent, service filtering, quote calculator, and a validated contact form.

## Features
- Industrial UI (dark steel + orange accent)
- Responsive navigation + mobile menu
- Services section with category filters (Vanilla JS)
- Reference “work log” cards
- Quote estimator (hourly rate + materials + rush multiplier)
- Contact form with lightweight validation (demo)

## Tech stack
- HTML5
- CSS3 (responsive layout)
- Vanilla JavaScript (filters, calculator, form validation)

## Run locally
Open `index.html` in a browser or use **Live Server** in VS Code.

## Notes
This is a portfolio demo. No real quote requests are sent.
