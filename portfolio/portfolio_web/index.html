Avaaminen lokaalisti

Suositus: VS Code Live Server, jotta linkit ja reitit toimivat helposti.

Vaihtoehto 1: Live Server

  1. Avaa kansio 10_portfolio_site VS Codessa
  2. Avaa portfolio/portfolio_web/index.html
  3. Right click → Open with Live Server

Vaihtoehto 2: suoraan selaimessa

Voit avata tiedoston suoraan, mutta joissain asetuksissa selain rajoittaa tiettyjä toimintoja.

Tämä hub-sivu toimii yleensä hyvin myös suoraan (file://), koska linkit ovat suhteellisia.
