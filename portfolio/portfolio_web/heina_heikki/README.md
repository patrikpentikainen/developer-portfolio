# Heinä-Heikki Website

## Description
Heinä-Heikki is a simple static website created as part of my web development learning portfolio.  
The project focuses on practicing the fundamentals of HTML structure and basic CSS styling.

This project represents one of my first steps in building complete web pages using separate files for structure, styling, and behavior.

---

## Features
- Basic HTML page structure
- Header and content sections
- External CSS file for styling
- JavaScript file prepared for future functionality

---

## Technologies Used
- HTML
- CSS
- JavaScript

---

## Learning Focus
In this project, I practiced:
- Creating a valid HTML document structure
- Linking external CSS and JavaScript files
- Separating content, styling, and logic
- Organizing files in a clean project structure

---

## Possible Improvements
- Add navigation or multiple pages
- Improve layout using Flexbox or Grid
- Add JavaScript-based interactivity
- Enhance visual design and responsiveness
