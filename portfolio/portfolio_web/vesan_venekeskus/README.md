# Vesan Venekeskus (portfolio demo)

A light “marine UI” demo page for a boat harbor / service center.
Designed to look different from the dark templates: soft blue gradients, clean pricing tables, and a booking estimate widget.

## Sticky header / anchor fix
This demo includes an anchor offset fix so headings are not hidden under the sticky header:
- `html { scroll-padding-top: ... }`
- `section { scroll-margin-top: ... }`

## Features
- Light marine theme (sea/sky palette)
- Sticky navigation + mobile menu
- Service cards + pricing tables
- Booking estimate widget (service + boat length + add-ons)
- Contact form with lightweight validation (demo)

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` or use VS Code **Live Server**.
